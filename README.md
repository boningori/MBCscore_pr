# MBCscore - ミニバス スコアシート

MBCscoreは、ミニバスケットボールの試合記録をデジタル化し、簡単かつ直感的に管理できるプログレッシブウェブアプリ（PWA）です。
スマートフォンやタブレットにインストールして、ネイティブアプリのような操作感で使用できます。

## 📱 PWAとしての特徴（アプリとしてインストール）

このアプリはPWA（Progressive Web App）に対応しており、ブラウザから直接デバイスにインストールできます。

- **インストール可能**: ホーム画面に追加して、アプリとして起動できます。アドレスバーやブラウザのメニューが非表示になり、広い画面で操作できます。
- **オフライン対応**: 一度読み込めば、インターネット接続がない体育館でも問題なく動作します。写真読み込み（OCR）も含め、記録・保存・出力といった主要機能はすべてオフラインで動きます（音声メモのみGemini APIキー設定時・オンライン時の補助機能です）。
- **高速な動作**: キャッシュ機能を活用し、ページの読み込みが高速です。
- **全画面表示**: 没入感のある全画面モードでスコア記録に集中できます。
- **ホーム画面アイコンのショートカット**: アイコンを長押しすると「新規試合開始」「試合履歴」「選手スタッツ分析」へ直接移動できます。

### インストール方法

ホーム画面に**「📲 ホーム画面に追加できます」の案内**が出ている場合は、そこから進めるのが簡単です。

- **Android / PC (Chrome・Edge)**: 案内内の「ホーム画面に追加」ボタンを押すと、ブラウザのインストール確認が開きます。
- **iPhone / iPad (Safari)**: 案内に手順が表示されます。「共有」→「ホーム画面に追加」→「追加」の順にタップしてください。

案内は、すでにインストール済みの場合と、一度「×」で閉じた場合には表示されません。その場合は次の方法でインストールできます。

1. **iPhone/iPad (Safari)**: 「共有」ボタンアイコンをタップし、「ホーム画面に追加」を選択します。
2. **Android (Chrome)**: メニューアイコンをタップし、「アプリをインストール」または「ホーム画面に追加」を選択します。
3. **PC (Chrome/Edge)**: アドレスバーの右端にあるインストールアイコンをクリックします。

### アプリの更新について

新しいバージョンが公開されると、画面下部に**「新しいバージョンがあります」**というバーが表示されます。「更新」を押すと再読み込みして最新版に切り替わり、「後で」を押すとそのまま使い続けられます。

- **試合の記録中は更新の案内を出しません。** 更新は再読み込みを伴うため、記録の手が止まらないよう、試合が終わるかホーム画面に戻ってから表示されます。
- 案内を出さずに勝手に更新することはありません。記録中に表示中のアプリが入れ替わって不具合が起きるのを防ぐためです。

## ✨ 主な機能

### 🎯 フリック入力 - 高速スコア記録
このアプリ最大の特徴は**フリック入力**によるスコア記録です。

- **上フリック → 成功**: シュートボタンを上方向にフリックすると得点を記録。
- **下フリック → ミス**: 下方向にフリックするとシュートミス（2PA/3PA/FTA）を記録。
- **タップ → 選択**: タップすると成功/ミスを選択するポップアップが表示。

視線を画面に向けたまま直感的に操作できるため、試合のテンポを崩さず記録できます。

### ⏳ 保留処理 - 「あとで決定」できる柔軟な入力
試合中は「誰の得点か分からない」「番号を見逃した」という場面が頻繁に発生します。
MBCscoreの**保留処理**機能は、そうした場面に対応します。

1. **アクション先行入力**: まずアクション（得点・ファウル等）を記録。
2. **選手は後から指定**: 選手が確認できた時点でタップして紐付け。
3. **複数保留にも対応**: 連続したプレーも順番に処理可能。

これにより、記録漏れを防ぎながら試合のペースに追従できます。

### 📱💻 2つの表示モード - デバイスに合わせた最適なUI

MBCscoreは**フルモード**と**シンプルモード**の2つの表示モードを切り替えて使用できます。

| モード | 推奨デバイス | 特徴 |
|--------|------------|------|
| **フルモード** | タブレット（iPad等） | 3カラムレイアウトで両チームの選手一覧とアクションボタンを同時表示。詳細なスタッツ記録に最適。 |
| **シンプルモード** | スマートフォン | 縦型レイアウトで得点・ファウルに特化。大きなボタンでスマホでも快適に操作可能。 |

画面右上のモード切替ボタンでいつでも変更できます。

### 1. 試合管理
- **チーム設定**: 自チームと対戦チームの名前、チームカラー（白/青など）を設定可能。
- **選手登録**: 背番号（ビブス番号・ユニフォーム番号）、名前、コートネームを登録・管理。
- **クイック選手登録**: 選手名未入力でも背番号だけで即座に登録可能。
- **試合情報の編集**: 大会名、日時、会場、ゲームナンバーなどの試合情報を入力・編集可能。
- **履歴保存**: 過去の対戦チーム情報を記憶し、再対戦時に素早く呼び出し可能。

### 2. スコア & スタッツ記録
- **得点**: 2点、3点、フリースロー(FT)をワンタップまたはフリックで記録。
- **ボタン配色の最適化**: 得点（緑系）、ファウル（赤系）、タイムアウト（黄系）など、直感的に判別しやすい配色を採用。
- **スタッツ**: リバウンド（ORボタン/DRボタンで直接記録）、アシスト、スティール、ブロック、ターンオーバーを詳細に記録。
- **シュートミス**: シュート成功だけでなく、失敗（2PA/3PA/FTA）も記録可能。
- **選手交代**: 直感的なUIで選手交代とコート上のメンバー管理が可能。トグルスイッチ（緑=表示/赤=非表示）でベンチメンバーの表示切替もスムーズ。
- **クォーター管理**: Q1〜Q4のクォーター切り替えに対応。
- **タイムアウト記録**: 各チームのタイムアウト使用をクォーターごとに記録。経過時間も記録可能。

### 3. ファウル管理
- **専用ファウル入力画面**: ファウルの種類を段階的に選択できる専用入力フロー。
- **個人ファウル**: 5ファウル退場に加え、D（ディスクォリファイイング）1つ、T・U 合わせて2つの失格も判定して警告表示。なお出場そのものは止めません（練習試合の運用に配慮した仕様）。
- **チームファウル**: チームごとのファウル数を自動集計し、ボーナス状態を表示。
- **テクニカル/アンスポ**: テクニカルファウルやアンスポーツマンライクファウルにも対応。
- **コーチ・ベンチ**: コーチテクニカル(C)、ベンチテクニカル(B)も記録可能。

### 4. 履歴・編集機能
- **アクション履歴**: 記録した全てのアクション（得点、ファウル、スタッツ）を時系列で確認。
- **記録の取り消し**: アクション履歴から誤った記録を削除・修正して、いつでも訂正可能。
- **修正・削除**: 間違って記録したデータの削除や、選手・アクション種別の修正が可能。
- **成功/失敗の変換**: 「シュート成功」を「シュートミス」に、またはその逆に後から変更可能。
- **試合詳細のタブ**: 履歴から試合を開くと、まず両チームのスタッツを見比べる「チーム比較」タブが表示されます。選手別のスタッツ表は「スタッツ（画面表示）」タブ、保存・PDF出力は「スコアシート（保存/PDF）」タブに分かれています。

### 5. JBA公式様式に準拠したランニングスコアシート
- **公式様式準拠**: JBA（日本バスケットボール協会）の公式スコアシート様式に準拠したA4縦レイアウト。※JBA公認・提携アプリではありません。
- **自動生成**: 試合中の記録データから、ランニングスコア・選手ロスター・ファウル記録・出場時限・チームファウルを自動反映。
- **斜線描画の最適化**: スコアシート上の斜線や取り消し線が正確に描画されるよう調整済み。
- **各Q得点表示**: クォーターごとの得点内訳を自動計算して表示。
- **勝利チーム・試合終了時間**: 試合終了後に勝利チーム名と終了時間を記録。
- **PDF/画像エクスポート**: スコアシートをPDFまたは高解像度画像として保存・共有可能。

### 6. 💾 データのバックアップと移行 (New!)
大切な試合データを安全に管理するための機能が強化されました。

- **フルバックアップ**: すべてのチームデータ、試合履歴、設定を含む完全なバックアップファイル（JSON形式）を作成・保存できます。機種変更時のデータ移行に最適です。
- **データ復元**: バックアップファイルからデータを一括復元できます。
  - **既存データは消えません**: 復元は常に「マージ」です。同じデータがあれば新しい方に更新され、無いデータは追加されます。復元によって既存の記録が削除されることはありません。
  - **確認フロー**: 実行前に「何件が新規で、何件が上書きされるか」の内訳が表示され、そこで初めて実行できます。
- **CSVエクスポート**: 試合データをCSV形式で出力し、ExcelやSpreadsheetで詳細な分析が可能です。

#### バックアップ・復元の手順

いずれもホーム画面右上の**⚙️（設定）→「📊 データ管理」**から行います。設定画面は項目ごとに折りたたまれているので、見出しをタップして開いてください。見出しには最終バックアップ日時が表示されます。

**保存する**
1. 「💾 今すぐクラウド/ファイルに保存」を押します。
2. スマホでは共有シートが開くので、Google DriveやiCloud等に保存します（非対応の環境ではそのままダウンロードされます）。

**復元する**
1. 「📂 ファイルから復元」を押してバックアップファイルを選びます。
   - 他の端末からコピーしてきた場合は「📝 データを貼り付けて復元」も使えます。
2. すぐ下に**確認パネル**が開き、復元される内容の内訳が表示されます。
3. 内容を確認し、パネル内の**「全データをインポート（上書き）」**を押すと復元されます。

> [!NOTE]
> 復元を確定するのは**確認パネル内のボタン**です。画面下部の「設定を保存」は、AIのAPIキーと既定のゲームモードを保存するためのもので、復元とは関係ありません。
>
> なお、確認パネルを開いたまま他の項目（「ヘルプ」など）を開くと、読み込んだデータは破棄されます。その場合は手順1からやり直してください。

### 7. 📸 OCR選手登録（対戦チーム）
- **カメラ読込**: メンバー表やスコアブックをカメラで撮影して選手リストを自動作成。
- **対象は対戦チームの登録のみ**: 「対戦チーム管理」および試合設定の対戦チーム選択画面で使えます。マイチームの選手登録は手入力またはJSONインポートで行ってください。
- **ハイブリッドOCRシステム**:
  - **基本モード (オフライン)**: Tesseract.jsを使用。APIキー不要で、オフライン環境でも動作します。認識に必要なデータはアプリに同梱されているため、通信は一切発生しません。
  - **高精度モード (AI)**: Google Gemini APIキーを設定（ホーム画面右上の⚙️→「AI機能 (Google Gemini API)」）することで、手書き文字や複雑な表も高精度に認識できるAI-OCR機能が有効になります。こちらは通信が必要です。
  - ※APIキーは端末内（ブラウザ）にのみ保存されます。OCR実行時にはGoogleのAPIサーバーへ送信されますが、当プロジェクトや第三者のサーバーには送信・保存されません。

> [!IMPORTANT]
> **プライバシーに関するご注意**  
> OCR機能では選手名や背番号など個人情報を含む画像を処理します。
> Gemini APIを使用する場合、**有料プラン（従量課金）の使用を推奨します**。
> 無料版（API Free tier）では、送信データがモデル改善に使用される可能性があります。
> 詳細は[Google AI Studio利用規約](https://ai.google.dev/terms)をご確認ください。

### 8. 🎤 音声メモ（読み上げ用の下書き）
試合中に見聞きしたことを声で残せる、手入力を助けるための補助機能です。
- **フルモードの記録画面限定**: ヘッダー中央の🎤ボタンを押している間だけ録音し、離すと文字起こしされて「メモ」から読めます。
- **利用条件**: 設定でONにしたうえで確認ダイアログに同意し、ご自身のGemini APIキー（OCR高精度モードと共通）を設定し、オンラインである必要があります。いずれか欠けるとボタンは出ないか無効になります。
- **スタッツには反映されません**: 文字起こしされた文章はあくまで読み上げ用の下書きで、選手やスタッツへの自動入力は行われません。記録は引き続き手動で行ってください。
- **音声は保存されません**: 録音した音声そのものは送信後に破棄され、端末にもサーバーにも残りません。文字起こし結果も試合中のみ保持され、試合が終了・破棄されると消え、バックアップやエクスポートにも含まれません。

### 9. その他の便利機能
- **Toast通知**: 操作完了時やエラー時に、画面下部にわかりやすい通知メッセージ（Toast）を表示。
- **統計表示**: チームごとの詳細な統計データの閲覧。試合中の統計画面と履歴の試合詳細では、両チームのスコアやシュート成功率、各種スタッツを左右に並べて比較する「チーム比較」画面も見られます。すでに記録済みのデータから作成しているため、過去に保存した試合もそのまま比較表示できます。3Pを使っていない試合では該当行が「—」表示になり、3P未使用の注記が添えられます。
- **アプリ設定**: Gemini APIキー、デフォルトゲームモード（フル/シンプル）などの設定を管理する設定画面。

## 🚀 開発と実行

### 必要要件
- Node.js (v18以上推奨)
- npm

### ローカルでの実行
```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

### ビルドとプレビュー
PWAの動作確認を行うにはビルドが必要です。

```bash
# ビルド
npm run build

# プレビュー（ビルド後のアプリを確認）
npm run preview
```

## 🛠 プロジェクト構成
- **Frontend**: React 19, TypeScript
- **Build Tool**: Vite
- **PWA**: vite-plugin-pwa
- **UI Components**: Toast notifications, Modal dialogs
- **OCR**: Tesseract.js (On-device), Google Gemini API (Optional)
- **PDF/Image**: jspdf, html2canvas
