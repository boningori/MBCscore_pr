1. はじめに

1.1 MBCscoreとは

MBCscoreは、ミニバスケットボールの公式スコアシートをタブレットやスマートフォンで記録できるWebアプリケーションです。 試合中の得点・ファウル・統計データをリアルタイムに記録し、公式スコアシート形式で出力できます。

主な特徴
  • タブレット最適化の3列レイアウト / スマホ対応のシンプルモード
  • 得点・ファウル・リバウンド・アシスト等のリアルタイム記録
  • ミニバスルール対応（5ファウル退場、クォーター出場管理）
  • 公式スコアシート形式でのPDF / JPEG出力
  • 選手スタッツの試合横断分析・成長可視化
  • オフライン動作 / 自動セッション保存（中断復帰対応）

1.2 動作環境

項目推奨環境
デバイスiPad / Androidタブレット（10インチ以上推奨）/ スマートフォン
ブラウザChrome, Safari, Edge（最新版）
ネットワーク初回読み込み後はオフラインで動作可能
推奨
タブレット横向き（ランドスケープ）での使用を強く推奨します。フルモードの3列レイアウトにより、両チームの選手とアクションボタンを一画面で操作できます。

1.3 アプリの起動

ブラウザでアプリのURLにアクセスすると、ホーム画面が表示されます。PWA対応のため、ホーム画面に追加してアプリのように使用することも可能です。

3. 初期設定 — マイチーム登録

試合を開始するには、最低1つの「マイチーム」を登録する必要があります。

3.1 チーム作成

  1. ホーム画面で 「👥 マイチーム管理」 をタップ
  2. + 新規チーム作成 をタップ
  3. チーム名を入力（例: 〇〇ミニバスクラブ）
  4. 選手を登録（下記参照）
  5. 保存 をタップして完了

3.2 選手登録

チーム編集画面で選手を1人ずつ登録します。各選手に以下の情報を設定できます:

項目必須説明
ビブス番号○練習着（ビブス）の番号。0〜99および00が使用可能（「0」と「00」は別の番号として扱われます）
ユニフォーム番号公式ユニフォームの番号（ビブス番号と異なる場合に設定）
選手名○フルネームまたはニックネーム
キャプテンキャプテンの場合はチェック（Cマーク表示）
ビブス番号とユニフォーム番号
ミニバスでは練習時のビブス番号と試合時のユニフォーム番号が異なることがあります。 両方登録しておくと、試合設定時にどちらの番号を使用するか選択できます。

3.3 データのインポート

他の端末からエクスポートしたチームデータ（JSONファイル）を読み込むことができます。 マイチーム管理画面の 「インポート」 ボタンからファイルを選択、 またはJSONテキストを直接貼り付けてインポートできます。

4. 対戦チーム管理

対戦相手のチームを事前に登録しておくことで、試合設定がスムーズになります。 ホーム画面の 「🆚 対戦チーム管理」 から登録します。

対戦チームには背番号と選手名を登録します（番号のみでも可）。 試合中に対戦チーム側の選手を追加することも可能です。

対戦したチームは自動的に「最近の対戦チーム」として保存され、次回以降すぐに選択できます。

5. 試合設定（新規試合開始）

ホーム画面で 🏀 新規試合開始 をタップすると、5ステップの設定ウィザードが表示されます。

1. 試合情報 → 2. マイチーム → 3. 出場選手 → 4. 対戦チーム → 5. 確認

Step 1: 試合情報

  • 試合名 / 大会名（任意）: 大会名や回戦情報を入力（例: 冬季大会 第1回戦）。 空欄のままでもOKで、その場合は「日付 vs 対戦相手」の形で自動的に試合名が付きます。
  • 日付: 試合日を選択（デフォルトは当日）
過去に使用した試合名が入力欄の候補として表示されるので、同じ大会の複数試合を素早く設定できます。 自動で付いた試合名は、確認画面（Step 5）で 「自動」 バッジ付きで確認できます。

Step 2: マイチーム選択

登録済みのマイチーム一覧から使用するチームをタップして選択します。ここから「チーム管理・新規登録」画面に移動することも可能です。

Step 3: 出場選手確認

選択したチームの全選手が一覧表示されます。当日欠席の選手はチェックを外してください。

出場選手は最低5名必要です。5名未満では次のステップに進めません。

Step 4: 対戦チーム選択

登録済みの対戦チーム、または最近の対戦チームから選択します。未登録の場合はその場で新規登録も可能です。

Step 5: 設定確認

最終確認画面では以下を設定・確認します:

項目説明
使用番号タイプマイチームの番号を「ビブス番号」「ユニフォーム番号」のどちらで表示するか選択
3Pシュート3P入力ボタンを「使う / 使わない」から選択。ミニバスには3Pが無いため通常は「使わない」（U15/一般で使う場合は「使う」）
クォーター時間「6分（公式）」「5分」から選択。タイムアウト記録の残り時間入力に反映されます（延長は常に3分）
チームカラー白チーム / 青チームの割り当て。⇄ チームカラー入れ替えで変更可能
「3Pシュート」と「クォーター時間」は、試合中でもスコアボード横の ⚙（試合オプション）から変更できます。
チームカラーと配置
白チームは常に画面左側（Team A）、青チームは画面右側（Team B）に配置されます。 これはスコアシートの表記規則に準拠しています。

確認後、試合開始 をタップするとスタメン選択画面に移ります。

6. スタメン選択（クォーターラインナップ）

各クォーター開始前に、両チームのコート上5名を選択する画面が表示されます。 画面上部の白 / 青のタブで対象チームを切り替えて選択します。 タブは白（Team A）が左・青（Team B）が右で固定ですが、 どちらのチームから選んでも構わず、途中で何度でも切り替えられます。

  1. 上部のタブで 白チーム / 青チーム を切り替え（どちらからでも構いません）
  2. 出場させる5名の選手カードをタップして選択（チェックマーク表示）
  3. もう一方のタブに切り替えて、同じように5名を選択
  4. 両チームとも5名揃ったら 試合開始（1Q）または Q○ 開始 をタップ
タブの表示で選択状況がひと目でわかる
各タブにはチームカラー（白 / 青）とチーム名に加えて、「3/5」のように選択人数が表示されます。 5名揃ったタブには ✓ が付くので、タブを切り替えなくても両チームの進み具合を確認できます。
開始ボタンが押せないとき
開始ボタンは両チームとも5名選択されるまで無効です。 ボタンの下に 「白のスタメンが未選択です（3/5）」 のように、 どちらのチームが何名足りないかが表示されるので、そのタブに切り替えて選択を完了してください。
画面上部に現在のスコアを表示
ヘッダーのすぐ下に、白チーム・青チームの現在の得点が左右に並んで表示されます。 第2クォーター以降のスタメン選択でも、試合画面に戻らずにその場でスコアを確認しながら 出場選手を決められます。得点はチーム名の右側に大きく表示され、チームカラー（白 / 青）のバッジ付きで区別されます。
出場クォーター表示と出場ルールの目安
各選手カードの下部に「1 2 3 4」のクォーター表示があり、出場済みのクォーターが色付きで表示されます。 ミニバスの出場ルール（最低2Q・最大3Q・全員出場）の目安に達しない場合は、選手カードに 「3Q超」「2Q未達」 のバッジ、画面下部に 「未出場」 の案内が表示されます。
警告はあくまで「目安」です
上記の出場ルール表示は目安であり、強制ではありません。 登録人数が少なく条件を満たせないチームでも、警告が出たまま問題なく試合を開始・記録できます。
試合画面から戻ってきたときは
スタメン選択画面から試合画面に戻った場合でも、Q終了 後の スコアボードに表示される スタメン選択へ ボタンで、 この画面をもう一度開けます（7.9 クォーター管理 参照）。

7.2 画面構成（シンプルモード）

シンプルモードはスマートフォン向けのコンパクトなレイアウトです。 ヘッダーの 📱 シンプル / 💻 フル ボタンで切り替えます。

  • 選手は3列のコンパクトなカード表示
  • アクションボタンはシュート（2P / 3P / FT）とファウルに絞られます
  • リバウンド・アシスト等の統計ボタンは非表示

7.3 得点の記録

得点を記録するには、2つの入力方法があります:

方法A: 選手を先に選択 → アクションボタン

  1. チームパネルから得点した選手のカードをタップ（緑色にハイライト）
  2. 中央の 2P 3P FT のいずれかをタップ
  3. 得点が記録され、スコアに反映されます

方法B: アクションを先に選択 → チーム → 選手（先行入力）

  1. 中央の 2P 3P FT のいずれかをタップ
  2. チーム選択モーダルが表示されるので、該当チームをタップ
  3. 「保留アクション」として画面端に表示され、後から選手を指定して確定します
スワイプ操作（フルモード）
シュートボタンはスワイプ操作に対応しています:
上にスワイプ → シュート成功（得点加算）
下にスワイプ → シュートミス（試投数のみ加算）
タップした場合は選択肢が表示されるので、「成功」「ミス」を選んでください。

7.4 ファウルの記録

選手選択 → ファウル → 種類選択（P/T/U/D） → FT本数・シューター → FT結果

ファウルした選手のカードをタップして選択し、 ⚠️ ファウル をタップすると、ファウル種類の選択画面が表示されます。

記号種類説明
Pパーソナル通常のファウル
Tテクニカルテクニカルファウル
Uアンスポーツマンライクアンスポーツマンライクファウル
Dディスクォリファイイング失格ファウル
重要 — P（パーソナル）ボタンはタップと長押しで使い分けます
タップ = 通常のファウル: そのまま記録されます（ファウルした側のチームがペナルティ状態＝そのクォーターのチームファウルが4個に達している場合は、続けて相手チームのフリースロー入力に進みます）。
長押し = シュート中のファウル: シュートファウルとして扱われ、下記のシュート状況選択に進みます。

P（パーソナル）でシュート中のファウルを記録する場合

  1. Pボタンを長押しし、「2Pシュート中」「3Pシュート中」のいずれかを選択（3Pシュートを「使わない」設定の試合ではこの選択はスキップされ、自動的に2Pシュート中として扱われます）
  2. シュートが成功したか（バスケットカウント → FT1本）／失敗か（2P=FT2本 / 3P=FT3本）を選択

T・U・D の場合

T / U / D はタップすると、そのままフリースロー本数の選択画面（自動提案あり）に進みます。

フリースロー（FT）の入力

FTが発生する場合は、以下の順で入力します:

  • FT本数の確認・選択（自動提案あり）
  • シューターの選択（相手チームのコート上の選手一覧から）
  • 各FTの成功 / 失敗をタップして記録
5ファウル退場
個人ファウルが5つに達すると自動で警告が表示されます。退場した選手はスタメン選択画面で選択できなくなります。
チームファウルとペナルティ
各クォーターのチームファウルが4つ以上になるとペナルティ状態となり、FTの本数が自動的に提案されます。

7.6 選手交代

  1. チームパネル下部の 交代 ボタンをタップ
  2. 交代モーダルが表示されます
  3. 退く選手（コート上）を選択
  4. 入る選手（ベンチ）を選択
  5. 交代実行 をタップ
未登録の選手が急遽出場する場合は、交代モーダル内の「選手追加」フォームから背番号と名前を入力してその場で追加できます。

7.7 ベンチファウル

コーチやベンチ関係者のファウルは、チームパネル下部の ベンチファウル から記録します。

種類記録先説明
コーチ (C)コーチ行に「C」監督本人のテクニカルファウル
A.コーチ (C)A.コーチ行に「C」+ コーチ行に「B」アシスタントコーチのテクニカル
交代要員 (T)選手行に「T」+ コーチ行に「B」ベンチの選手のテクニカル（選手を選択）
ベンチ関係者 (B)コーチ行に「B」引率者等のテクニカル

7.8 タイムアウト

スコアボード上の「タイムアウト」ボタンをタップすると、 経過時間入力モーダルが表示されます。何分経過時点のタイムアウトかを記録します。

7.9 クォーター管理

スコアボードの Q終了 ボタンでクォーターを進行します。

Q1 試合中 → Q終了 → Q2 スタメン選択 → Q2 開始 → ... → 試合終了

第4クォーター終了時に自動的に試合終了画面が表示されます。

スタメン選択画面に戻る
Q終了 を押した後（次のクォーターが始まるまでの間）、 スコアボードに スタメン選択へ ボタンが表示されます。 スタメン選択画面から試合画面に戻ってしまった場合でも、このボタンから次のクォーターのスタメンを選び直せます。 フルモード・シンプルモードのどちらでも表示され、次のクォーターが開始されると自動的に消えます。
┌─────────────────────────────────────────────┐ │ 白 32 Q1 終了 28 青 │ ├─────────────────────────────────────────────┤ │ [ Q2へ ] [ スタメン選択へ ] │ │ [ 終了を取り消す ] │ └─────────────────────────────────────────────┘
同点の場合は延長（オーバータイム）または引き分け終了
第4クォーター終了時に同点の場合、確認画面で「延長戦へ」か「試合を終了する」（引き分けのまま終了）を選択できます。 大会規定で延長を行わない場合は「試合を終了する」を選んでください（記録上は引き分けとして集計されます）。 「延長戦へ」を選ぶと通常のクォーターと同様にスタメン選択画面が表示されます。 延長は第4クォーターの延長として扱われるため、チームファウルはリセットされず通算されます。

8. 操作のコツ — 先行入力と保留アクション

試合中は展開が速いため、選手を確認する前にアクション（得点・統計）だけを先に記録したい場面があります。 MBCscoreでは「先行入力」方式に対応しています。

先行入力の流れ

  1. アクションボタン（例: 2P）を選手未選択の状態でタップ
  2. チーム選択モーダルが表示 → 該当チームをタップ
  3. 「保留アクション」として画面の左下（白チーム）or 右下（青チーム）にパネル表示
  4. 後から選手を特定して保留パネルから選手を選択して確定
┌───────────────────────────────────────────────┐ │ 試合画面 │ │ │ │ ┌──────────────┐ │ │ │ 保留アクション│ ← 白チーム側に表示 │ │ │ DRリバウンド │ │ │ │ コート上の候補:│ │ │ │ [#4] [#5] [#7]│ ← タップで確定 │ │ │ [#8] [#10] │ │ │ │ [不明] [削除] │ ← 選手不明 or 取消 │ │ └──────────────┘ │ └───────────────────────────────────────────────┘
保留アクションの活用シーン
  • 速攻の得点で、背番号が見えなかった場合
  • リバウンドの選手を確認する間に次のプレーが始まった場合
  • 複数のアクションが短時間に発生した場合
リバウンド等の統計アクションのみ、「不明」のまま確定することもできます（チーム統計には反映されますが個人成績には加算されません）。 得点とファウルは「不明」にできません。選手を特定して確定するか、削除してください。

9. アクション履歴 — 編集・削除・変換

フルモードでは各チームパネルの下部にアクション履歴が表示されます。 また、ヘッダーの 📜 履歴 ボタンから両チームの履歴をポップアップ表示できます。

履歴での操作

操作説明
タップ編集モーダルを開く
編集選手の変更、シュート種別の変更が可能
成功⇔ミス変換得点をミスに変換（例: 2P成功 → 2Pミス）、またはミスを成功に変換
OG（オウンゴール）得点エントリにオウンゴールフラグを切り替え

ファウルを削除すると、関連するフリースロー得点も自動的に削除されます。 誤操作に注意してください。

10. スコアシート

ヘッダーの 📄 スコアシート をタップすると、 公式スコアシート形式の画面が表示されます。

スコアシートの内容

  • 両チームの選手一覧（背番号・名前・キャプテンマーク）
  • 各選手のファウル記録（クォーターごとにP/T/U/D表示）
  • ランニングスコア（得点経過）
  • クォーターごとのスコア集計
  • タイムアウト記録
  • 試合情報（大会名、日付、会場など）

試合情報の編集

スコアシート画面で「試合情報を編集」ボタンをタップすると、 以下の情報を追加・編集できます:

  • 試合基本情報: 会場、Game No.（試合番号）、開始時間、終了時間
  • 審判: クルーチーフ、アンパイア
  • TO（テーブルオフィシャルズ）: スコアラー、A・スコアラー、タイマー、ショットクロックオペレーター

出力

PDF出力 JPEG出力

スコアシート画面の出力ボタンで、PDF形式またはJPEG画像形式でダウンロードできます。 試合終了後の提出用スコアシートとして利用できます。

スコアシートは試合中いつでも確認でき、現時点までの記録がリアルタイムに反映されます。

16. データ管理（バックアップ・復元）

MBCscoreのデータはすべてブラウザのローカルストレージに保存されています。 端末の買い替えや別端末での利用には、データのエクスポート・インポートが必要です。

エクスポート方法

  • 全データバックアップ: 設定画面 → 「全データエクスポート」（チーム・試合履歴すべて）
  • チーム単位: マイチーム管理 → チーム編集画面 →「エクスポート」
  • 試合単位: 試合履歴 → 試合を選択 →「エクスポート」
  • CSV出力: 設定画面 →「CSV出力」（試合一覧 / 詳細統計）

インポート方法

以下のいずれかの方法でデータを取り込めます:

  1. ファイル選択: JSONファイルを選択してインポート
  2. テキスト貼り付け: JSONテキストを直接貼り付け（リアルタイムバリデーション付き）
データの取り扱いについて
  • ブラウザのデータを消去すると、アプリのデータもすべて失われます
  • 定期的なバックアップをお勧めします
  • 異なるブラウザ間ではデータは共有されません

17. よくある質問（FAQ）

Q: 試合中にブラウザを閉じてしまいました。データは消えますか？

A: 試合データは自動的に保存されています。アプリを再度開き、ホーム画面の ▶️ 試合を再開 をタップしてください。

Q: 得点を間違えて入力しました。修正できますか？

A: アクション履歴から該当の記録をタップし、選手の変更・シュート種別の変更・削除が可能です。 また「成功⇔ミス変換」で得点をミスに変更することもできます。

Q: 選手を5名未満で試合を開始できますか？

A: いいえ。ミニバスのルールに従い、各チーム最低5名の選手が必要です。

Q: 試合中に選手を追加できますか？

A: はい。交代モーダル内の「選手追加」フォームから、背番号と名前を入力して追加できます。

Q: フルモードとシンプルモードはいつでも切り替えられますか？

A: はい。試合中でもヘッダーのモード切替ボタンでいつでも変更できます。 データは共有されているので、切り替えによるデータ損失はありません。

Q: 他のタブレットにデータを移したいです。

A: 設定画面の「全データエクスポート」でJSONファイルをダウンロードし、 新しい端末のアプリ設定画面でインポートしてください。

Q: スコアシートをそのまま提出できますか？

A: スコアシート画面からPDFまたはJPEGで出力できます。 公式スコアシートの形式に準拠していますが、大会の規定については主催者にご確認ください。

Q: 対戦チームの選手番号がわからない場合は？

A: 背番号のみで登録可能です。名前は空でも構いません。 また、試合中に交代モーダルから選手を追加することもできます。
